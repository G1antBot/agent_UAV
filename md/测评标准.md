# 评测指标体系升级：自定义 → 行业标准

## 背景

当前 `test_exp2.py` 的评测指标存在以下问题：
- `execution_success_rate` 只看"代码是否报错"，不评"任务目标是否达成"
- `semantic_depth_score` 只比较数字接近度，无法评估方向、顺序、约束
- `robustness_index` 和 `zero_shot_success_rate` 高度重叠
- `colloquial_tolerance_rate` 没有数据，一直为 0

参考 ALFRED (CVPR 2020)、VLN SPL (arXiv 2018) 和 SayCan (arXiv 2022)，升级为行业标准指标。

#### 改动 3：重写 `_evaluate_semantic_depth` → `_evaluate_semantic_fidelity`（L448-477）

**新算法**（多维评分，每个维度 0-25 分，总分 0-100）：

```python
def _evaluate_semantic_fidelity(instruction_text, expected_behavior, generated_code, 
                                  parsing_success, execution_success, execution_time_ms):
    if not parsing_success:
        return 0.0
    
    score = 0.0
    key_params = str(expected_behavior.get("key_params", ""))
    
    # 维度1: 目标正确性 (25分) — target= 中的目标是否出现在代码中
    target_match = re.search(r"target=(\w[\w\s]*)", key_params)
    if target_match:
        target = target_match.group(1).strip()
        target_cn = _target_en_to_cn(target)  # "red balloon" → "红色气球"
        if target_cn in generated_code or target in generated_code:
            score += 25.0
        else:
            score += 0.0
    else:
        score += 25.0  # 无目标约束，默认满分

    # 维度2: 参数精度 (25分) — 数值参数（距离/角度/速度）的匹配程度
    expected_nums = _extract_numbers(key_params)
    code_nums = _extract_numbers(generated_code)
    if expected_nums and code_nums:
        best_ratio = min(abs(c - e) / max(abs(e), 0.01) for e in expected_nums for c in code_nums)
        if best_ratio <= 0.2: score += 25.0
        elif best_ratio <= 0.5: score += 15.0
        else: score += 5.0
    elif not expected_nums:
        score += 25.0  # 无数值约束，默认满分
    
    # 维度3: 动作正确性 (25分) — 期望动作关键词是否在代码/结果中体现
    action_text = str(expected_behavior.get("primary_action", ""))
    action_keywords = re.findall(r"[\u4e00-\u9fff]+", action_text)
    if action_keywords:
        matched = sum(1 for kw in action_keywords if kw in generated_code or kw in instruction_text)
        score += min(25.0, (matched / len(action_keywords)) * 25.0)
    else:
        score += 25.0

    # 维度4: 执行有效性 (25分) — 执行成功 + 执行时间合理（>500ms）
    if execution_success and execution_time_ms > 500:
        score += 25.0
    elif execution_success:
        score += 10.0  # 执行太快，可能是空操作
    
    return round(score, 1)
```

#### 改动 4：新增 `_evaluate_task_completion`

```python
def _evaluate_task_completion(execution_success, execution_time_ms, 
                               error_type, summary) -> bool:
    """
    TCR: 比 execution_success 更严格的判定。
    参考 SayCan: 规划成功 + 物理执行成功 = 任务完成。
    """
    if not execution_success:
        return False
    # 执行时间过短（<500ms）说明可能是空代码/无操作
    if execution_time_ms < 500:
        return False
    # 有错误类型标记的不算完成
    if error_type and error_type != "N/A":
        return False
    return True
```

#### 改动 5：新增 `_calc_execution_efficiency`

```python
def _calc_execution_efficiency(results):
    """
    EE: 参考 VLN SPL 思想。
    理论基准时间 = 简单指令5s, 中等10s, 复杂20s。
    EE = mean(min(baseline / actual, 1.0)) × 100
    """
    BASELINE = {"L1": 5.0, "L2": 10.0, "L3": 20.0}
    ratios = []
    for r in results:
        if not r.execution_success:
            ratios.append(0.0)
            continue
        baseline_s = BASELINE.get(r.difficulty, 10.0)
        actual_s = r.execution_time_ms / 1000.0
        if actual_s < 0.5:  # 空操作
            ratios.append(0.0)
        else:
            ratios.append(min(baseline_s / actual_s, 1.0))
    return (sum(ratios) / len(ratios)) * 100 if ratios else 0.0
```

```python
def _calc_generalization_robustness(results):
    """
    GR: 合并原 robustness_index + zero_shot_success_rate。
    同语义不同表述的成功率均值（涵盖 zero_shot 和 colloquial 组）。
    """
    non_core = [r for r in results if r.group != "core"]
    if not non_core:
        return 100.0  # 无泛化测试数据时默认满分
    grouped = {}
    for r in non_core:
        key = r.origin_text or r.instruction_text
        grouped.setdefault(key, []).append(r)
    rates = []
    for items in grouped.values():
        success = sum(1 for r in items if r.task_completed)
        rates.append((success / len(items)) * 100.0)
    return sum(rates) / len(rates) if rates else 0.0
```
