等你回到有无人机和网络的环境后，你只需要按照下面这个极为简单的流程操作：

阶段一：在无人机端（RK3566）推流
通过 SSH 登录你的无人机：ssh 你的用户名@192.168.151.107
确认相机节点：运行 ls /dev/video\*，看出来的是 /dev/video0 还是其他的（通常 MIPI 相机会挂在 0 上）。
开始网络直播：把下面这行命令直接复制到无人机终端里运行。这行代码的含义是以 640x480 的分辨率、30 帧的极低延迟，把画面 UDP 直播给你现在的 Windows 电脑（之前查到你的 IP 是 192.168.1.4）。
bash
gst-launch-1.0 v4l2src device=/dev/video0 ! video/x-raw,width=640,height=480,framerate=30/1 ! videoconvert ! x264enc tune=zerolatency bitrate=1000 ! rtph264pay ! udpsink host=192.168.1.4 port=5000
阶段二：在 Windows 接收
打开你项目里的 agent_config.json（如果没用 json，就找你定义 real_camera 配置的地方）。

把相机设备号 device_index 改成 UDP 的网络地址：

json
"real_camera": {
"source": "opencv",
"device_index": "udp://@0.0.0.0:5000",
"width": 640,
"height": 480,
"fps": 30
}
(注意：udp://@0.0.0.0:5000 表示监听电脑上所有的 5000 端口 UDP 数据)

直接正常运行你的 main.py 就可以了，Communication_Mavlink.py 就会自动抓取无人机的视频流。
