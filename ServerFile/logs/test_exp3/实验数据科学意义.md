# 实验三图表科学意义说明

> 本文档阐述 `visualize_exp3.py` 生成的 6 张实验图表在论文中的**科学定位、论证功能与写作指引**。
> 实验三聚焦于"基于视觉语言模型的无人机自然语言控制"系统在**多目标干扰环境下的视觉感知鲁棒性**。

---

## 实验设计概述

| 自变量 | 水平 | 说明 |
|--------|------|------|
| **靠近距离** | 2m / 4m / 6m | 目标在无人机前方的欧氏距离 |
| **干扰工况** | A / B / C | A=单目标（基线）、B=同类双目标（无消歧）、C=同类双目标+消歧指令 |
| **目标尺度** | 0.5× / 1.0× | 红色气球的缩放因子，影响 YOLO 检测置信度 |
| **重复次数** | 5 | 每组配置独立重复 5 次 |

总计: 3 × 3 × 2 × 5 = **90 试次**

### 核心评估指标

| 指标 | 缩写 | 定义 |
|------|------|------|
| 靠近成功率 | ASR | 无人机是否到达目标球 2.5m 范围内 |
| 消歧正确率 | DA | 工况 C 下是否靠近了指令指定的"左边"气球 |
| 终态靠近距离 | effective_dist | 无人机终态位置到最近有效目标的距离 (B 工况取 min) |
| 靠近耗时 | completion_time | 从指令下发到到达终态的耗时 |
| 轨迹曲折度 | tortuosity | 实际轨迹长度 / 起点到目标欧氏距离 |

## Fig 1 — 靠近成功率 × 距离 × 工况 (ASR Grouped Bar Chart)

**文件**: `fig1_asr_by_distance_condition`

### 科学定位
靠近成功率（Approach Success Rate, ASR）是评估视觉伺服控制系统在多目标干扰下**端到端可用性**的最核心指标。本图将 ASR 沿**距离 × 干扰工况**二维展开，构成 3 × 3 的分组柱状图。

### 论证功能
1. **多目标鲁棒性验证**：通过对比工况 A（单目标基线）与工况 B/C（双目标干扰），直接回答"多目标环境是否显著降低靠近成功率"这一核心研究问题。若三工况 ASR 均接近 100%，则证明方案 D（Center-First + Bbox Tracker + Spatial Hint）有效消除了多目标干扰。
2. **距离鲁棒性验证**：2m → 4m → 6m 的距离梯度验证系统在不同作战距离下的稳定性。远距离下目标在画面中占比更小，对 YOLO 检测和视觉伺服的挑战更大。
3. **消歧机制有效性**：工况 C 的 ASR 是否与工况 A 持平，验证空间语义解析（"左边"→ 画面 x 坐标最小）的端到端有效性。

### 论文写作建议
- 作为**实验结果章节的开篇 Hero Panel**，一图传达核心结论："系统在全部 90 次试次中 ASR 达到 100%"。
- 若某些组合 ASR 未达 100%，应结合日志逐案分析失败原因（搜索超时、漂移守护触发等）。
- 底部标注 Overall ASR 和样本量 n，满足论文定量引用需求。

## Fig 2 — 靠近耗时 × 距离 × 工况 (Completion Time Boxplot)

**文件**: `fig2_completion_time`

### 科学定位
靠近耗时是衡量视觉伺服控制系统**任务效率**的关键指标。本图使用箱线图展示耗时在三个距离 × 三个工况下的分布特征，揭示距离和干扰条件对执行效率的定量影响。

### 论证功能
1. **距离–耗时线性关系验证**：理想的视觉伺服控制器应呈现"距离越远、耗时线性增加"的规律。箱线图的中位数趋势应大致符合 `t ∝ d / v_approach` 的物理模型。
2. **多目标干扰的时间代价量化**：工况 B/C 相比工况 A 的耗时增量揭示了多目标场景下"搜索→锁定→跟踪"决策开销。若增量显著（如 B/C 耗时为 A 的 2-3 倍），则说明多目标目标选择引入了额外的自旋搜索或犹豫时间。
3. **方差分析**：箱体宽度和离群值数量反映系统一致性。方差小说明控制策略稳定；离群值指示偶发的"搜索困难"场景。
4. **与行业基准对比**：可与现有视觉伺服系统的响应时间对比，论证系统是否满足实际部署需求。

### 论文写作建议
- 适合放在**效率分析**小节。
- 应量化报告："2m 工况 A 中位耗时为 X 秒，6m 工况 B 中位耗时增至 Y 秒，增幅 Z%"。
- 讨论 B/C 相对于 A 的耗时增量是否可以接受。

## Fig 3 — 靠近精度 × 距离 × 工况 (Final Distance Strip Plot)

**文件**: `fig3_final_distance`

### 科学定位
终态靠近距离是衡量视觉伺服控制**精度**的核心指标。本图使用抖散点图（jitter strip plot）展示每次试次的终态距离，配合中位数黑线和 1.5m 成功阈值参考线。

### 关键设计决策
**B 工况使用 effective_dist = min(dist_to_target, dist_to_distractor)**：因为 B 工况指令为"靠近红色气球"，两个红色气球均为合法目标。`final_dist_to_target` 记录的是预设目标球，不代表靠近精度。使用 min 值才能反映系统的真实靠近能力。

### 论证功能
1. **精度均匀性验证**：若三个工况的散点分布高度重合（中位数差异 < 0.1m），则证明多目标干扰未影响靠近精度——系统在各条件下都能精确到达目标附近。
2. **尺度效应分析**：大尺度目标（1.0×）理论上提供更大的视觉信号，应对应更精确的靠近终态。散点的聚集程度验证这一假设。
3. **停止策略有效性**：终态距离的下界（约 1.0m）反映了视觉伺服控制器的停止策略——当目标 bbox 占画面比例达到阈值时停止前进。均匀的下界说明停止策略稳定可靠。
4. **阈值合理性验证**：1.5m 参考线以下的数据点占比验证 `APPROACH_DIST_OK = 2.5m` 阈值设定的合理性。

### 论文写作建议
- 适合放在**精度分析**小节，与 Fig 2 形成"效率–精度"双维度评估。
- 应报告所有工况的中位靠近距离和 IQR。
- 强调 B 工况的 effective_dist 设计理由，体现实验设计的严谨性。

## Fig 4 — 靠近精度热力图 (Approach Precision Heatmap)

**文件**: `fig4_asr_heatmap`

### 科学定位
热力图将终态靠近距离的**中位数**沿**距离 × 尺度 × 工况**三维展开，构成 6 × 3 的性能矩阵。色阶采用 RdYlGn_r 色板（绿=近/好，红=远/差），直观展示因素间的交互效应。

### 论证功能
1. **三因素交互效应可视化**：单独分析距离、工况、尺度各因素的主效应容易遗漏交互效应。热力图在一张图中同时展示三个因素的联合影响，例如"6m × B × 0.5 是否为精度最差的组合"。
2. **尺度因素的实际影响量化**：对比同一行中 ×0.5 和 ×1.0 的数值差异，量化目标尺度对靠近精度的贡献。若差异不显著（< 0.1m），则说明 YOLO 检测器对目标尺度的敏感度低，系统具有尺度鲁棒性。
3. **最优/最劣工况定位**：色阶自动高亮最佳（绿色）和最差（红色）组合，为工程优化指明方向。
4. **与实验一/二的跨实验对比**：精度热力图提供了标准化的展示框架，便于与其他实验条件下的精度进行横向对比。

### 论文写作建议
- 适合放在**因素交互分析**小节。
- 应结合方差分析（ANOVA）讨论各因素的主效应和交互效应是否统计显著。
- 与 Fig 3 形成"个体分布 → 聚合矩阵"的递进分析。

## Fig 5 — 靠近耗时累积分布 (Completion Time CDF)

**文件**: `fig5_time_cdf`

### 科学定位
累积分布函数（CDF）提供耗时的**完整概率分布视角**，弥补箱线图仅展示五数概括的局限。按距离着色的三条 CDF 曲线直观展示不同距离下的耗时分布差异。

### 论证功能
1. **百分位数分析**：CDF 可直接读取任意百分位数。例如"90% 的 2m 试次在 X 秒内完成，而 90% 的 6m 试次需要 Y 秒"，为系统的超时阈值设定提供数据支撑。
2. **分布形状差异**：三条曲线的间距和斜率反映不同距离下的耗时分布特征。若曲线平行，说明距离仅引起平移（均值增加）而不改变方差；若曲线斜率不同，说明远距离引入了更大的不确定性。
3. **长尾行为识别**：CDF 右端的收敛速度揭示是否存在耗时异常长的试次（长尾效应）。长尾通常对应"搜索困难 + 多次自旋"的场景。
4. **超时阈值校准**：当前设定 `TRIAL_TIMEOUT_S = 30s`。CDF 显示几乎所有试次在 25s 内完成，证明超时阈值设定合理且留有安全余量。

### 论文写作建议
- 适合放在**时效性深度分析**小节，作为 Fig 2 的补充。
- 应标注关键百分位数值（P50, P90, P95）并在正文中引用。
- 中位数虚线标注使三个距离组的中位差异一目了然。

## Fig 6 — 综合评估摘要表 (Summary Table)

**文件**: `fig6_summary_table`

### 科学定位
以表格形式精确呈现系统在所有评估指标上的**分组汇总数值**，提供**可引用的定量结论**。9 组数据行 + 1 行总计，覆盖 3 距离 × 3 工况的完整因素空间。

### 表格字段说明

| 列名 | 含义 | 统计方式 |
|------|------|---------|
| 距离 | 目标距离 (2m/4m/6m) | 分组变量 |
| 工况 | 干扰条件 (A/B/C) | 分组变量 |
| n | 样本量 | 计数 |
| ASR | 靠近成功率 | 百分比 |
| 耗时 | 靠近耗时 | 中位数 ± 标准差 |
| 终态距离 | effective_dist | 中位数 ± 标准差 |
| 曲折度 | 轨迹曲折度 | 中位数 |
| 消歧正确率 | 仅工况 C 有效 | 百分比 |

### 论证功能
1. **精确数值参考**：图表可视化展示趋势，但论文引用系统指标时需要精确数值。每个指标的 med ± std 格式满足学术论文的报告规范。
2. **曲折度指标的独特价值**：曲折度（tortuosity）是本表独有的指标，反映无人机是否"直奔目标"还是"迂回前进"。理想值为 ~0.9（因视觉伺服需要微调航向，不可能完全直线）。B/C 工况的曲折度若接近 A 工况，说明多目标目标锁定后的路径规划质量未受影响。
3. **消歧正确率的独立验证**：消歧正确率（DA）独立于 ASR，回答"无人机是否靠近了正确的那个气球"。90% 的 DA 意味着空间语义解析在大多数情况下正确工作，少数失败可能因首帧检测时两个气球距离过近导致 bbox 排序歧义。
4. **跨研究对比基础**：标准化的指标名称和格式便于其他研究者引用和对比。

### 论文写作建议
- 适合作为**实验结果章节的定量锚点**，置于章节首部或尾部。
- 论文正文引用数值时应注明"如表 X 所示"。
- 高亮总计行的 ASR=100% 和消歧正确率=90%，作为核心结论。
- 对曲折度的物理意义做专门解释：值越接近 1.0 说明路径越直接，越接近 0 说明存在严重迂回。

### 核心技术创新点（可在论文中强调）

1. **方案 D: Center-First + Bbox Tracker + Spatial Hint**
   - 首帧根据空间语义词（"左"/"右"）选择目标 bbox
   - 后续帧通过空间最近邻 bbox 跟踪，不受置信度抖动影响
   - 5 帧丢失阈值处理遮挡/短暂目标丢失

2. **B 工况的 effective_dist 设计**
   - 两个同名目标场景下，靠近任一均算成功
   - 体现"无消歧指令时任一合法目标均可"的工程合理性

3. **实验设计的三因素正交矩阵**
   - 距离 × 干扰 × 尺度的完全正交设计
   - 支持三因素方差分析（Three-way ANOVA）
